# 01. 무엇을 왜 설치하나

## 한 줄 요약

> 이 강좌는 **도구 설치**가 전부입니다. 아래 표의 도구를 깔고, 확인 스크립트가 전부 ✅ 를 찍으면 끝.
> 이 도구들은 뒤따르는 **7개 강좌 전체**에서 반복해서 쓰입니다.

## 1. 도구별 "왜 필요한가"

| 도구 | 어느 강좌에서 | 왜 필요한가 |
|------|---------------|-------------|
| **터미널** (Windows: PowerShell 7) | 01-cli 부터 전부 | 개발 도구는 대부분 글자 명령으로 다룹니다. Windows 기본 5.1 보다 **7** 이 빠르고 macOS 와 명령이 비슷해 배우기 좋습니다 |
| **Git** | 02-git, 그리고 모든 실습 | 코드의 변경 이력을 기록하고 GitHub 로 협업합니다 |
| **VS Code** | 전 강좌 | 코드 편집기. 확장으로 ESP32·Git·Python 까지 한 곳에서 다룹니다 |
| **PlatformIO** (VS Code 확장) | 03-esp32 | ESP32 에 코드를 컴파일·업로드합니다. 컴파일러·보드 정의를 자동 관리 |
| **Git Graph** (VS Code 확장) | 02-git | 커밋·브랜치를 **그래프로** 봐서 rebase·merge 를 눈으로 이해합니다 |
| **Python 3.12** | 05-python, 06-web-server | 파이썬 프로그래밍과 FastAPI 웹서버 |
| **uv** | 05-python, 06-web-server | 파이썬 **프로젝트·패키지·가상환경**을 하나로 관리. 동아리 표준 도구 (`pip`/`venv` 안 씀) |
| **Codex CLI** | 07-ai | 터미널에서 쓰는 AI 코딩 에이전트. 말로 시키면 코드를 만들고 고칩니다 |

> 💡 **macOS 는 Python 과 Git 이 이미 있습니다.** Git 은 Xcode Command Line Tools 에, Python 3 은
> 시스템에 포함됩니다. 다만 파이썬 프로젝트는 **uv 가 필요한 버전을 따로 받아 관리**하므로 시스템
> 파이썬 버전은 신경 쓰지 않아도 됩니다.

## 2. 설치 방식 — 패키지 관리자

프로그램을 하나씩 사이트에서 내려받아 "다음 → 다음" 을 누르는 대신, **패키지 관리자**에게 이름을
알려 주고 한 번에 설치합니다. 이 강좌의 스크립트가 하는 일이 바로 이것입니다.

| OS | 패키지 관리자 | 예 |
|----|---------------|----|
| **Windows** | **winget** (Windows 10/11 기본 내장) | `winget install --id Git.Git` |
| **macOS** | **Homebrew** (스크립트가 없으면 설치) | `brew install uv` |

> 💡 패키지 관리자로 설치하면 **업데이트도 한 줄**(`winget upgrade --all`, `brew upgrade`)입니다.

## 3. 전체 흐름

```
① 스크립트 실행 (설치)  →  ② 확인 스크립트 (전부 ✅?)  →  ③ 수동 설정 3가지
   winget / brew 로            버전 출력·확장 확인            · Git 이름/이메일
   도구 일괄 설치                                               · Codex 로그인 (브라우저)
                                                                · VS Code 첫 실행
```

수동 설정 3가지는 **로그인·개인 정보 입력**이 필요해 스크립트로 자동화하지 않습니다. 각 OS 문서의
뒷부분에서 사진과 함께 안내합니다.

## 4. 준비물

- 인터넷 연결 (설치 파일 다운로드, 합쳐서 1~2GB 정도)
- **관리자 권한** 은 대부분 필요 없습니다 (사용자 범위 설치). Windows 에서 winget 이 UAC 창을 띄우면 **예** 를 누르세요
- **GitHub 계정** (02-git 에서 사용 — 미리 만들어 두면 좋음): https://github.com/signup
- **ChatGPT 계정** (Codex 로그인용 — 07-ai 에서 사용)
