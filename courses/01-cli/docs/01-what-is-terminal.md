# 01. 터미널이란?

## 한 줄 요약

> **터미널 = 마우스 대신 "글자 명령"으로 컴퓨터에 일을 시키는 창.**
> 개발 도구(git·uv·codex·서버 실행)는 대부분 터미널에서 다루므로, 개발의 첫걸음은 터미널과 친해지는 것입니다.

## 1. 터미널이 뭔가요?

평소 우리는 폴더를 **더블클릭**하고 버튼을 **마우스로 눌러** 컴퓨터를 씁니다. 터미널은 그 대신
**글자로 명령을 입력**해 같은 일을 시키는 창입니다. **하는 일은 똑같고, 방법만 다릅니다.**

| 하고 싶은 일 | 탐색기 / Finder 에서 | 터미널에서 |
|--------------|---------------------|------------|
| 폴더 만들기 | 우클릭 → 새 폴더 | `mkdir 새폴더` |
| 폴더 열기(들어가기) | 더블클릭 | `cd 새폴더` |
| 상위 폴더로 | ← 뒤로 / 위로 버튼 | `cd ..` |
| 안에 뭐가 있나 보기 | 창에 보이는 목록 | `ls` |
| 지금 어느 폴더인가 | 주소창 | `pwd` |

> 💡 처음엔 "왜 굳이 글자로?" 싶지만, 개발 도구들은 대부분 터미널 명령으로 동작합니다.
> 몇 개만 익히면 마우스보다 훨씬 빠르고 정확하며, **다른 사람과 명령을 그대로 공유**할 수 있습니다.

### 조금 더 정확하게 — 터미널 · 셸 · 운영체제

"터미널" 이라고 뭉뚱그려 부르지만, 실제로는 세 층이 나눠서 일합니다.

```
 나            터미널               셸(shell)                 운영체제(OS)             하드웨어
 ⌨️ ──입력──▶ [글자 창]  ──한 줄──▶ [명령 해석기]  ──실행──▶ [파일·프로세스·네트워크] ──▶ 디스크·NIC
 👀 ◀──출력── (화면 표시) ◀──결과── PowerShell / zsh  ◀──결과── 커널 (시스템 콜)
```

| 층 | 정체 | 하는 일 | 예 |
|----|------|---------|----|
| **터미널** | 글자를 넣고 보여 주는 **창** | 키 입력을 셸에 전달하고, 셸이 내보낸 글자를 화면에 그림. 원래는 메인프레임에 연결된 진짜 단말 장치(TTY)였고, 지금은 그걸 흉내 내는 **터미널 에뮬레이터** 프로그램 | Windows Terminal, macOS Terminal.app, VS Code 안의 터미널 패널 |
| **셸** | 명령을 **해석하고 실행하는 프로그램** | 한 줄을 읽어 → 띄어쓰기로 명령·인자·옵션을 쪼개고 → 그 이름의 프로그램을 찾아(PATH) 실행하고 → 끝나면 결과를 돌려주고 다시 프롬프트를 띄움 | PowerShell 7 (Windows), zsh (macOS), bash (Linux) |
| **운영체제(커널)** | CPU·메모리·디스크·네트워크를 관리하는 **자원 관리자** | 프로그램이 "이 폴더 만들어 줘", "이 파일 읽어 줘", "이 주소로 연결해 줘" 라고 요청하면(**시스템 콜**) 실제 하드웨어에 수행 | Windows, macOS |

- `mkdir`·`git`·`uv`·`python` 은 셸의 일부가 아니라 **셸이 실행해 주는 별개의 프로그램**입니다. 그래서 설치가 안 돼 있으면 셸이 "그런 명령 없음" 이라고 합니다.
- 탐색기(Finder)도 결국 같은 OS 기능을 **마우스로** 부르는 프로그램입니다. 셸은 그 기능을 **글자로** 부르는 인터페이스, 즉 **사용자와 OS 사이의 글자 통역사**입니다.
- 프로그램이 화면에 찍는 글자(표준 출력)와 키보드 입력(표준 입력)은 셸을 거쳐 터미널로 오갑니다. 04 강좌의 `input()`/`print()` 가 바로 이 통로를 씁니다.

## 2. 프롬프트 읽기

터미널을 열면 이런 줄이 보이고, 그 뒤에 명령을 입력합니다. 이 줄을 **프롬프트(prompt)** 라고 합니다.

```
PS C:\Users\나\projects>      ← Windows PowerShell 7
나@맥북 projects %             ← macOS (zsh)
```

- 프롬프트에는 보통 **지금 내가 있는 폴더(현재 위치)** 가 표시됩니다. 탐색기의 주소창과 같습니다.
- `>` 또는 `%` 뒤에 명령을 치고 **Enter** 를 누르면 실행됩니다.
- 명령이 끝나면 다시 프롬프트가 나타납니다. 프롬프트가 안 보이면 **아직 실행 중**이라는 뜻입니다.

## 3. OS별 터미널 열기

| OS | 터미널 | 여는 법 |
|----|--------|---------|
| **Windows** | **PowerShell 7** (`pwsh`, 검은 아이콘) — 00 강좌에서 설치 | 시작 메뉴에서 `PowerShell 7` 또는 `Terminal` 검색. 탐색기 주소창에 `pwsh` 입력 → 그 폴더에서 열림 |
| **macOS** | 터미널(Terminal.app, zsh) | `⌘ + Space` → `터미널` |

> ⚠️ Windows 에는 파란 아이콘의 **옛 PowerShell 5.1** 도 있습니다. 헷갈리면 `$PSVersionTable.PSVersion` 을
> 쳐 보세요. `7.x` 가 나와야 합니다. 5.1 도 대부분 동작하지만 이 자료는 7 기준입니다.

> 💡 **VS Code 안에도 터미널이 있습니다.** `` Ctrl + ` `` (백틱, 숫자 1 왼쪽 키) 로 열립니다.
> 코드를 보면서 명령을 칠 수 있어 실습 때 가장 많이 쓰게 됩니다.

## 4. 알아두면 편한 기본 조작

| 조작 | 방법 |
|------|------|
| 직전 명령 다시 부르기 | **↑ (위 화살표)** — 여러 번 누르면 더 이전 명령 |
| 자동완성 | 일부만 치고 **Tab** — 폴더·파일·명령 이름을 완성해 줌. **가장 중요한 습관!** |
| 실행 중인 명령 멈추기 | **Ctrl + C** (서버를 끌 때도 이걸 씀) |
| 화면 지우기 | `clear` (Windows 는 `cls` 도 됨) |
| 붙여넣기 | 우클릭 또는 `Ctrl + V` (macOS `⌘ + V`) |
| 터미널 닫기 | `exit` |

> 💡 **Tab 자동완성**을 쓰면 오타가 줄고, 긴 폴더 이름을 전부 칠 필요가 없습니다.
> `cd Doc` + Tab → `cd Documents` 처럼요.

## 5. 명령의 생김새 — 프로그램 · 인자 · 옵션

셸은 한 줄을 **띄어쓰기**로 쪼개서 첫 단어를 프로그램 이름으로, 나머지를 그 프로그램에 넘기는 값으로 봅니다.

```
mkdir  my-project
└─┬─┘  └───┬────┘
프로그램   인자(대상)

ls  -la
    └┬┘
    옵션 (동작 방식을 바꿈, - 로 시작)
```

조금 더 복잡한 명령도 같은 조각으로 나뉩니다:

| 명령 한 줄 | 프로그램 | 하위명령 | 옵션 (값) | 인자(대상) |
|-----------|----------|----------|-----------|-----------|
| `rm -r old-folder` | `rm` | — | `-r` | `old-folder` |
| `git commit -m "로그인 수정"` | `git` | `commit` | `-m "로그인 수정"` | — |
| `uv run --python 3.12 main.py` | `uv` | `run` | `--python 3.12` | `main.py` |
| `code .` | `code` | — | — | `.` (지금 폴더) |

| 부분 | 뜻 | 규칙 |
|------|----|------|
| **프로그램** | 무엇을 실행할지 | 첫 단어. 셸이 PATH 에 등록된 폴더들에서 같은 이름의 실행 파일을 찾아 실행 |
| **하위명령** | 큰 프로그램 안의 기능 이름 | `git commit`, `uv run`, `codex login` 처럼 프로그램 바로 뒤 |
| **인자(argument)** | 무엇에 대해 — 파일·폴더·이름 | 띄어쓰기로 구분. 이름에 공백이 있으면 따옴표: `cd "My Folder"` |
| **옵션(option, flag)** | 어떻게 — 동작 방식 변경 | `-r` 처럼 `-` 하나에 글자 하나(짧은 형), `--recursive` 처럼 `--` 에 단어(긴 형). 둘은 같은 뜻인 경우가 많음 |
| **옵션의 값** | 옵션에 딸린 값 | `-m "메시지"`, `--port 8000`, `--python 3.12` 처럼 옵션 바로 뒤 |

- 짧은 옵션은 붙여 쓸 수 있습니다: `ls -l -a` = `ls -la`. 긴 옵션은 읽기 쉬워 문서·스크립트에 적합합니다.
- 순서는 보통 `프로그램 [하위명령] [옵션들] [인자들]` 이지만, 대부분의 프로그램은 옵션과 인자 순서를 바꿔도 이해합니다.
- **모르는 명령은 `명령 --help`** (또는 `-h`). PowerShell 자체 명령은 `Get-Help 명령`. 옵션 목록이 다 나오므로 외울 필요가 없습니다.
- PowerShell 의 자체 명령(`Get-ChildItem`, `New-Item`)은 옵션이 `-Recurse`, `-ItemType File` 처럼 `-` 하나에 단어 형태입니다. `ls`, `rm` 같은 별칭으로 부르면 대체로 macOS 와 같은 짧은 옵션도 통합니다.
