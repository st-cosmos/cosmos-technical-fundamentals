# 02. 폴더 오가기 — pwd · ls · cd · mkdir

## 한 줄 요약

> **터미널에서 폴더를 오가는 건 "서랍장에서 서랍을 여닫는 것"과 같습니다.**
> 지금 어느 서랍인지(`pwd`), 안에 뭐가 있는지(`ls`), 다른 서랍으로 이동(`cd`), 새 서랍 만들기(`mkdir`) —
> 이 4개면 시작 충분. **탐색기에서 하던 일을 글자로 하는 것뿐입니다.**

## 1. 폴더 비유 — "지금 열어둔 서랍"

컴퓨터의 폴더 구조는 **서랍장**과 같습니다. 큰 서랍 안에 작은 서랍이 들어 있습니다.

```
C:\Users\나\            ← 큰 서랍 (내 홈 폴더)          macOS: /Users/나/
   ├── Documents\       ← 그 안의 서랍
   └── workspace\       ← 그 안의 서랍 (00 강좌에서 만든 동아리 작업 폴더)
        └── web-01\     ← 또 그 안의 서랍
```

탐색기(Finder)를 열면 항상 **"어떤 폴더 하나"를 보고 있는 상태**죠. 터미널도 똑같이 항상
**"지금 열어둔 서랍 하나"**(= **현재 폴더**, current directory / working directory) 안에 있습니다.
명령은 특별히 말하지 않으면 **지금 그 서랍**을 기준으로 동작합니다.

> 💡 이게 이 강좌 전체의 핵심 아이디어입니다. **"나는 지금 어느 폴더에 있나?"** 를 항상 의식하세요.
> 탐색기에서 잘못된 폴더에 파일을 만드는 것과 같은 실수가 터미널에서도 똑같이 일어납니다.

## 2. 핵심 4개 명령어

### `pwd` — 지금 어느 서랍이야? (현재 위치)

```
pwd
```

현재 폴더의 전체 경로를 보여 줍니다. 탐색기의 **주소창**과 같습니다. "길을 잃었을 때" 가장 먼저 치는 명령입니다.

### `ls` — 이 서랍 안에 뭐가 있어? (목록 보기)

```
ls
```

현재 폴더 안의 파일·폴더 목록을 보여 줍니다. 탐색기에서 **폴더 창에 보이는 것**과 같습니다.

### `cd` — 다른 서랍으로 이동 (change directory)

```
cd workspace          # workspace 서랍 안으로 들어가기 (더블클릭)
cd ..                 # 한 칸 밖(상위 폴더)으로 나오기 (← 뒤로/위로 버튼)
cd ~                  # 홈 폴더로 한 번에
cd workspace/web-01   # 여러 칸 한 번에 들어가기
```

> 💡 폴더 이름이 길면 앞 글자만 치고 **Tab** → 자동완성됩니다. 이름에 **띄어쓰기**가 있으면
> 따옴표로 감쌉니다: `cd "My Projects"`.

### `mkdir` — 새 서랍 만들기 (make directory)

```
mkdir web-01       # 지금 폴더 안에 web-01 폴더 생성 (우클릭 → 새 폴더)
```

## 3. 네 명령을 이어서 써 보면

```
pwd            → C:\Users\나                          "지금 홈이구나"
cd workspace   →                                      "workspace 서랍으로 들어가서" (00 에서 만든 동아리 작업 폴더)
pwd            → C:\Users\나\workspace                "잘 들어왔나 확인"
mkdir web-01   →                                      "새 서랍 하나 만들고"
ls             → cosmos-technical-fundamentals web-01 "목록에 보이네 — 저장소 옆에 생겼다"
cd ..          →                                      "한 칸 밖으로"
pwd            → C:\Users\나                          "홈으로 돌아왔다"
```

> 📁 동아리 규칙: 실습 폴더·프로젝트는 전부 **`~/workspace` 안에** 만듭니다. 홈 폴더가 어지러워지지 않고,
> 어느 문서의 `cd ~/workspace/...` 도 그대로 통합니다.

> 💡 **`cd` 한 뒤엔 `pwd`, `mkdir` 한 뒤엔 `ls`** — 명령이 잘 됐는지 눈으로 확인하는 습관을 들이세요.

## 4. 조금 더 — 자주 쓰는 명령어

| 하고 싶은 일 | Windows (PowerShell 7) | macOS (zsh) |
|--------------|------------------------|-------------|
| 현재 위치 | `pwd` | `pwd` |
| 목록 보기 | `ls` | `ls` |
| 숨김까지 자세히 | `ls -Force` | `ls -la` |
| 폴더 이동 / 상위로 / 홈으로 | `cd 폴더` / `cd ..` / `cd ~` | 같음 |
| 폴더 만들기 | `mkdir 이름` | `mkdir 이름` |
| 빈 파일 만들기 | `New-Item 파일 -ItemType File` | `touch 파일` |
| 파일 내용 보기 | `cat 파일` | `cat 파일` |
| 파일 복사 / 이동(이름 바꾸기) | `cp 원본 대상` / `mv 원본 대상` | 같음 |
| 파일 삭제 | `rm 파일` | `rm 파일` |
| 폴더 삭제(내용 포함) | `rm -r 폴더` | `rm -r 폴더` |
| VS Code 로 현재 폴더 열기 | `code .` | `code .` |
| 화면 지우기 | `clear` (또는 `cls`) | `clear` |

> 💡 **PowerShell 7 의 장점**: `ls`, `pwd`, `cd`, `cat`, `cp`, `mv`, `rm` 같은 이름을 macOS 처럼 그대로
> 쓸 수 있습니다(별칭). 그래서 이 표의 좌우가 거의 같습니다. (정식 이름은 `Get-ChildItem`·`Set-Location`
> 등이지만 별칭만 알아도 충분합니다.)

> ⚠️ **삭제는 되돌릴 수 없습니다.** `rm` 은 휴지통을 거치지 않고 **바로 지웁니다.** 지우기 전에
> `pwd` 와 `ls` 로 지금 폴더와 대상 이름을 꼭 확인하세요.

## 5. `code .` — 터미널과 VS Code 를 잇는 한 줄

실습에서 가장 많이 쓰는 패턴입니다.

```
cd workspace/web-01     # 작업할 폴더로 이동
code .                 # 그 폴더를 VS Code 로 열기 ( . = 지금 폴더)
```

VS Code 가 열리면 안의 터미널(`` Ctrl + ` ``)은 **자동으로 그 폴더**에서 시작합니다.
