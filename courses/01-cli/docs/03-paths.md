# 03. 경로 — 절대 경로와 상대 경로 ★

## 한 줄 요약

> **경로(path) = 파일이나 폴더가 어디 있는지 적은 "주소".**
> **절대 경로**는 뿌리(root)부터 전부 적은 주소(집 전체 주소), **상대 경로**는 **지금 내가 있는 폴더 기준**으로
> 적은 주소("여기서 두 블록 앞"). 터미널의 거의 모든 실수는 경로에서 나오니, 이 문서는 천천히 읽으세요.

## 1. 경로는 "주소"다

우편 주소를 쓰는 방법이 두 가지 있듯이, 경로도 두 가지입니다.

| | 우편 주소로 비유 | 경로 |
|---|------------------|------|
| **절대(absolute)** | "서울시 강남구 테헤란로 1" — 어디서 말해도 같은 곳 | `C:\Users\나\workspace\web-01` |
| **상대(relative)** | "여기서 오른쪽으로 두 블록" — **지금 어디 있느냐**에 따라 달라짐 | `workspace\web-01`, `..\web-02` |

- 절대 경로는 **길지만 확실**합니다. 내가 어느 폴더에 있든 같은 곳을 가리킵니다.
- 상대 경로는 **짧지만 현재 위치에 의존**합니다. 같은 `..\web-02` 라도 내가 어디 있느냐에 따라 다른 곳입니다.

## 2. 절대 경로 — 뿌리부터 전부

폴더 구조의 **맨 꼭대기(뿌리, root)** 부터 시작하는 경로입니다. 뿌리의 모양이 OS 마다 다릅니다.

| OS | 뿌리 | 절대 경로 예 |
|----|------|--------------|
| **Windows** | 드라이브 문자 `C:\` | `C:\Users\나\workspace\web-01` |
| **macOS** | `/` (슬래시 하나) | `/Users/나/workspace/web-01` |

> 📌 **구분 기호**: Windows 는 `\`(역슬래시), macOS 는 `/`(슬래시). 다만 **PowerShell 과 대부분의 개발 도구는
> Windows 에서도 `/` 를 이해**하므로, 이 자료의 예제는 가능한 `/` 로 통일합니다. (`cd C:/Users/나` 도 됩니다)

### 절대 경로인지 알아보는 법

**시작이 `C:\` (드라이브) 또는 `/` 이면 절대 경로**입니다. 그 외는 전부 상대 경로.

```
C:\Users\나\workspace     절대 (C:\ 로 시작)
/Users/나/workspace       절대 (/ 로 시작)
workspace\web-01          상대 (그냥 이름으로 시작)
..\web-02                상대 (.. 로 시작)
./main.py                상대 (. 로 시작)
```

## 3. 상대 경로 — 지금 폴더 기준

**지금 내가 있는 폴더**에서 출발해 어디로 갈지 적습니다. 세 가지 특별한 기호를 씁니다.

| 기호 | 의미 | 비유 |
|------|------|------|
| `.` | **지금 폴더 자신** | "여기" |
| `..` | **한 칸 위(상위) 폴더** | "한 층 위" |
| `~` | **내 홈 폴더** (`C:\Users\나` / `/Users/나`) | "우리 집" — 어디서든 통하는 지름길 |

예를 들어 지금 위치가 `C:\Users\나\workspace\web-01` 이라면:

```
C:\Users\나\
   └── workspace\
        ├── web-01\        ← ★ 지금 여기 (pwd)
        │    ├── index.html
        │    └── css\
        │         └── style.css
        └── web-02\
             └── main.py
```

| 상대 경로 | 실제로 가리키는 곳 (절대 경로) | 읽는 법 |
|-----------|-------------------------------|---------|
| `.` | `C:\Users\나\workspace\web-01` | 여기 |
| `index.html` 또는 `./index.html` | `...\web-01\index.html` | 여기 안의 index.html |
| `css/style.css` | `...\web-01\css\style.css` | 여기 안의 css 안의 style.css |
| `..` | `C:\Users\나\workspace` | 한 칸 위 |
| `../web-02` | `C:\Users\나\workspace\web-02` | 한 칸 위로 나가서 web-02 로 |
| `../web-02/main.py` | `...\web-02\main.py` | 한 칸 위 → web-02 → main.py |
| `../..` | `C:\Users\나` | 두 칸 위 |
| `~/workspace` | `C:\Users\나\workspace` | 홈에서 workspace 로 (현재 위치와 무관) |

> 💡 `..` 는 여러 번 이어 쓸 수 있습니다. `../../..` 는 세 칸 위. 단, **뿌리보다 위로는 못 갑니다.**

### 왜 `./main.py` 처럼 `./` 를 붙이나?

`main.py` 와 `./main.py` 는 같은 뜻입니다. 다만 프로그램을 실행할 때 `./script.sh` 처럼 `./` 를 붙여
**"지금 폴더에 있는 이것"** 임을 명확히 하는 관습이 있습니다. (00 강좌의 `.\scripts\install-windows.ps1` 가 그 예)

## 5. 언제 무엇을 쓰나

| 상황 | 추천 | 이유 |
|------|------|------|
| 터미널에서 잠깐 이동 | **상대** (`cd ../web`) | 짧고 빠름 |
| 문서·스크립트에 적어 다른 사람과 공유 | **상대** (프로젝트 기준) | 사람마다 홈 폴더 이름이 달라 절대 경로는 남의 PC 에서 안 맞음 |
| 홈 아래 어딘가로 확실히 이동 | `~/...` | 어디 있든 통함 |
| 길을 잃었을 때 | `pwd` 로 절대 경로 확인 → `cd ~` 로 복귀 | 기준점 다시 잡기 |

> ⚠️ **흔한 실수**: 문서에 `cd courses/01-cli` 라고 쓰여 있는데 이미 `courses` 안에 있으면
> "그런 폴더 없음" 오류가 납니다. 상대 경로는 **문서가 가정한 시작 위치**가 있으니, 막히면 `pwd` 로 지금 위치를
> 확인하고 `cd ..` 로 맞추세요. 이 저장소의 문서는 별도 언급이 없으면 **저장소 최상위 폴더 기준**입니다.

## 6. 코드 안의 경로도 똑같다

경로 규칙은 터미널뿐 아니라 **HTML·Python·C++ 코드 안에서도 같습니다.**

```html
<link rel="stylesheet" href="css/style.css">   <!-- 이 HTML 파일 기준으로 css 폴더 안 -->
<img src="../images/logo.png">                 <!-- 한 칸 위의 images 폴더 -->
```

```python
open("data/led.json")        # 프로그램을 실행한 폴더 기준
```

```cpp
#include "config.h"          // 이 소스 파일이 있는 폴더(또는 include 폴더) 기준
```

> 💡 "파일을 못 찾는다" 는 오류의 대부분은 **기준 위치를 잘못 생각한 것**입니다. "이 경로의 기준이 어디지?" 를
> 먼저 물어 보세요. 03-web · 04-python 강좌에서 다시 만납니다.
