# 04. 네트워크 — 내 IP 확인 (ipconfig / ifconfig)

## 한 줄 요약

> **다른 기기(ESP32·폰)가 내 PC 서버에 접속하려면 내 PC 의 "실제 IP 주소"를 알아야 합니다.**
> Windows 는 `ipconfig`, macOS 는 `ipconfig getifaddr en0` 또는 `ifconfig` 로 확인합니다.

## 1. 왜 IP 를 알아야 하나?

이 동아리의 실습에서는 **내 PC 에 서버를 띄우고**, **ESP32 보드나 다른 사람의 브라우저가 그 서버에 접속**합니다.
다른 기기는 "내 PC" 가 어디 있는지 **IP 주소**로 찾아갑니다.

```
[내 PC] 192.168.0.10 : 웹서버 실행 (06-web-server)
   ▲                    ▲
   │ WiFi                │ WiFi
[친구 노트북]          [ESP32 보드]   ← http://192.168.0.10:8000 로 접속
```

> ⚠️ **`localhost` / `127.0.0.1` 은 "그 컴퓨터 자기 자신"** 을 뜻합니다. 그래서 ESP32 에서 `localhost` 로
> 접속하면 **ESP32 자신**을 찾으러 가서 실패합니다. 다른 기기에서 접속할 땐 반드시 **PC 의 실제 IP**
> (예: `192.168.0.10`)를 써야 합니다. (그리고 **같은 WiFi** 에 있어야 합니다)

## 2. 내 IP 확인하기

### Windows — `ipconfig`

```powershell
ipconfig
```

출력에서 지금 쓰는 연결(보통 **"무선 LAN 어댑터 Wi-Fi"**)의 **`IPv4 주소`** 를 찾습니다.

```
무선 LAN 어댑터 Wi-Fi:
   연결별 DNS 접미사. . . . :
   IPv4 주소. . . . . . . . . : 192.168.0.10      ← 이것!
   서브넷 마스크 . . . . . . . : 255.255.255.0
   기본 게이트웨이 . . . . . . : 192.168.0.1
```

> 💡 어댑터가 여러 개 나와 헷갈리면: **"기본 게이트웨이" 값이 있는 어댑터**가 실제로 인터넷에 연결된 것입니다.
> 유선이면 "이더넷 어댑터", 무선이면 "무선 LAN 어댑터 Wi-Fi".

> 💡 한 줄로 IPv4 만 뽑기: `ipconfig | Select-String IPv4`

### macOS — 한 줄 명령 또는 `ifconfig`

```bash
ipconfig getifaddr en0     # Wi-Fi IP 한 줄로 (보통 en0 이 Wi-Fi)
ifconfig                   # 전체 보기 → en0 의 "inet" 값 확인
```

`ifconfig` 출력에서는 `en0:` 항목의 `inet 192.168.0.10` 을 찾습니다. (`inet6` 는 IPv6 — 지금은 무시)

## 3. IP 주소 읽는 법

`192.168.0.10` 같은 주소는 보통 **집/학교 공유기(WiFi)가 각 기기에 나눠 준 사설 IP** 입니다.

| 앞부분 | 의미 |
|--------|------|
| `192.168.x.x` / `10.x.x.x` / `172.16~31.x.x` | **사설 IP** (같은 WiFi 안에서만 통함 — 우리 실습용) |
| `127.0.0.1` | **자기 자신**(localhost) |
| 그 외 (예: `8.8.8.8`) | 인터넷상의 공인 IP |

같은 공유기에 붙은 기기들은 앞 세 덩어리가 같습니다. PC 가 `192.168.0.10` 이면 ESP32 는 `192.168.0.21` 처럼요.
**앞부분이 다르면 같은 네트워크가 아니라서** 접속이 안 됩니다.

> 💡 IP 는 공유기에 다시 접속하거나 시간이 지나면 **바뀔 수 있습니다.** 접속이 안 되면 `ipconfig` 로
> **다시 확인**하는 것이 첫 번째 점검입니다.

## 4. 연결 확인 — `ping` (선택)

상대 기기까지 네트워크가 닿는지 간단히 확인할 수 있습니다.

```bash
ping 192.168.0.10          # Windows 는 4번 후 자동 종료 / macOS 는 Ctrl + C 로 멈춤
```

응답(`bytes=32 time=3ms` 같은 줄)이 오면 네트워크는 연결된 것 — 그래도 서버 접속이 안 되면 **방화벽**이
포트(예: 8000)를 막았을 가능성이 큽니다. (서버 실행 시 `--host 0.0.0.0`, 방화벽 허용은 06 강좌에서 안내)

## 5. 실습 서버 주소 조립하기

06·03 강좌에서 서버 주소를 이렇게 만듭니다.

```
http://192.168.0.10:8000
└┬─┘   └────┬─────┘ └┬─┘
 약속    PC 의 IP    포트 (서버가 듣는 "문" 번호)
```

- **내 PC 브라우저에서** 볼 때: `http://localhost:8000`
- **다른 기기에서** 볼 때: `http://<PC의 IP>:8000`

## 정리

- 다른 기기가 내 PC 를 찾는 주소 = **IP**. `localhost` 는 자기 자신이라 남이 못 씀
- Windows `ipconfig` → **IPv4 주소** / macOS `ipconfig getifaddr en0`
- 같은 WiFi + 바뀔 수 있으니 안 되면 **다시 확인**
