# 01. ESP32 소개 — MCU에 WiFi가 들어있다

## 한 줄 요약

> **ESP32 = 작은 컴퓨터(MCU) + WiFi·Bluetooth 무선 통신**이 **하나의 칩**에 들어 있는
> 부품. 그래서 "센서를 읽어 인터넷으로 보내는" 사물인터넷(IoT) 장치를 **칩 하나로** 만들 수
> 있습니다.

## 1. MCU(마이크로컨트롤러)가 뭔가요?

**MCU(Microcontroller Unit)** 는 *연산을 하는 CPU* + *프로그램과 데이터를 담는 메모리* +
*바깥세상과 연결되는 입출력 핀(GPIO)* 을 **하나의 칩에 모아 놓은 아주 작은 컴퓨터**입니다.

비유하자면:

- **데스크톱 PC** = 모니터·키보드·OS까지 갖춘 만능 컴퓨터 🖥️
- **MCU** = 화면도 OS도 없지만, **전기 신호를 읽고 쓰는 일**에 특화된 손톱만 한 컴퓨터 🔩

MCU는 보통 이런 일을 합니다.

- 핀에 들어온 전압을 읽기 (버튼이 눌렸나? 센서 값은?)
- 핀으로 전압을 내보내기 (LED 켜기, 모터 돌리기)
- 읽은 값으로 판단하고 동작하기 (어두워지면 불을 켜라)

> 💡 우리가 흔히 아는 **아두이노 우노(Arduino Uno)** 도 ATmega328이라는 MCU를 쓰는
> 보드입니다. ESP32도 같은 "MCU 보드" 종류이고, 훨씬 강력합니다.

## 2. ESP32의 핵심 — 무선 통신이 "내장"되어 있다

보통의 MCU(예: 아두이노 우노)로 인터넷에 연결하려면 **WiFi 모듈을 따로 사서 연결**해야
합니다. 반면 **ESP32는 WiFi와 Bluetooth가 칩 안에 이미 들어있습니다.**

이게 왜 중요할까요? 다음 한 줄이면 ESP32가 인터넷에 접속합니다.

```cpp
WiFi.begin("우리집_WiFi", "비밀번호");
```

즉 ESP32 하나로:

> 센서 값 읽기 → 판단 → **WiFi로 서버에 전송** → 응답 받아 동작

이 전체 흐름을 부품 하나로 처리할 수 있습니다. 이 자료의 선택 심화([08](08-wifi-http-client.md))가
바로 이 "WiFi로 서버에 요청 보내기"입니다.

## 3. 아두이노 우노 vs ESP32

| 항목 | 아두이노 우노 | **ESP32 DevKit** |
|------|---------------|------------------|
| CPU | 단일 코어, 16MHz | **듀얼 코어, 최대 240MHz** |
| RAM | 2KB | **약 520KB** |
| 플래시(코드 저장) | 32KB | **보통 4MB** |
| WiFi | ❌ (모듈 별도) | ✅ **내장** |
| Bluetooth | ❌ | ✅ **내장** (Classic + BLE) |
| 동작 전압 | 5V | **3.3V** ⚠️ |
| 아날로그 입력(ADC) | 10비트 (0~1023) | **12비트 (0~4095)** |
| 진짜 아날로그 출력(DAC) | ❌ | ✅ (GPIO25, 26) |
| 가격대 | 비슷하거나 ESP32가 더 저렴한 편 | |

> ⚠️ **중요: ESP32는 3.3V 부품입니다.** 5V를 핀에 직접 넣으면 보드가 손상될 수 있습니다.
> 센서나 부품을 연결할 때 동작 전압을 꼭 확인하세요. (자세한 주의는 [03](03-digital-output.md))

## 4. ESP32 보드 살펴보기

우리가 쓰는 건 정확히는 **"ESP32 DevKit"** 이라는 개발용 보드입니다. 핵심 칩(ESP32-WROOM-32)
하나만 있으면 다루기 불편하니, 보드 제작사가 다음을 함께 붙여 둔 형태입니다.

```
┌─────────────────────────────────────┐
│  [USB] ── USB-UART 칩 ── ESP32 칩    │  ← PC와 USB로 연결, 코드 업로드 + Serial 통신
│   포트     (CP2102/CH340)            │
│                                       │
│  [EN] 버튼   [BOOT] 버튼              │  ← 리셋 / 부트 모드 진입
│                                       │
│  좌우 양옆: GPIO 핀 헤더 (수십 개)    │  ← 여기에 LED·센서 등을 연결
│  내장 LED (보통 GPIO2)                │
└─────────────────────────────────────┘
```

- **USB 포트**: PC와 연결. **코드 업로드**와 **Serial 통신**을 모두 이 한 선으로 합니다.
- **USB-UART 변환 칩 (CP2102 또는 CH340)**: USB 신호를 ESP32가 알아듣는 신호로 바꿔줍니다.
  이 칩 때문에 PC에 **드라이버 설치**가 필요할 수 있습니다. ([02](02-development-environment.md)에서 다룸)
- **EN(리셋) 버튼**: 누르면 프로그램이 처음부터 다시 실행됩니다.
- **BOOT 버튼**: 업로드가 잘 안 될 때 사용 (대부분 자동이라 신경 쓸 일은 적습니다).
- **GPIO 핀**: General Purpose Input/Output. **우리가 LED·버튼·센서를 연결하는 곳.**
  ([03](03-digital-output.md)부터 본격적으로 다룹니다.)
- **내장 LED**: 보통 **GPIO2**에 연결돼 있어, 부품 없이도 첫 실습이 가능합니다.

## 5. ESP32로 뭘 만들 수 있나요?

- 🌡️ 온습도 센서 값을 읽어 **클라우드/서버로 전송**하는 환경 모니터
- 💡 스마트폰으로 켜고 끄는 **WiFi 스위치/조명**
- 🔘 버튼을 누르면 서버에 신호를 보내는 **IoT 버튼**
- 📟 작은 디스플레이에 정보를 띄우는 **위젯 장치**

공통점은 **"센서 입력 → 판단 → 통신/출력"** 이고, 우리는 이 자료에서 그 기본기를 차례로
배웁니다.
