# 05. PWM 출력 — LED 밝기 조절

## 한 줄 요약

> 디지털 핀은 3.3V 아니면 0V 만 낼 수 있습니다. 그런데 **아주 빠르게 켜고 끄기를 반복**하면 평균적으로
> **중간 밝기**처럼 보입니다. 이것이 **PWM (Pulse Width Modulation)**. `analogWrite(핀, 0~255)` 한 줄로 씁니다.

## 1. 왜 PWM 이 필요한가

[03](03-digital-output.md)의 `digitalWrite` 는 **켜짐/꺼짐 두 가지**뿐입니다. LED 를 "절반 밝기로", 모터를 "천천히"
돌리려면 **중간값**이 필요한데, 일반 GPIO 핀은 진짜 중간 전압(예: 1.65V)을 내지 못합니다.

대신 **켜짐/꺼짐을 초당 수천 번 반복**하되 **켜진 시간의 비율**을 조절합니다. 사람 눈(과 모터)은 그 평균만 느낍니다.

```
밝게:   ████████████████████  (거의 계속 켜짐 — 듀티 90%)
중간:   ██████████            (반반 — 듀티 50%)
어둡게: ███                   (잠깐만 켜짐 — 듀티 15%)
        ◀──── 한 주기 ────▶  (초당 수천 번 반복)
```

- **듀티(duty) 비율** = 한 주기 중 켜진 시간의 비율. 이 값이 "밝기"가 됩니다.
- **주파수** = 1초에 몇 번 반복하나. 눈에 깜빡임이 안 보일 만큼 빠릅니다(보통 1kHz 이상).

## 2. `analogWrite` — 아두이노식 PWM

아두이노에서 익숙한 `analogWrite()` 가 ESP32 에서도 동작합니다. 값 범위는 **0~255** (8비트).

```cpp
analogWrite(핀번호, 값);   // 0 = 항상 꺼짐, 255 = 항상 켜짐, 128 = 절반
```

| 값 | 듀티 | 밝기 |
|----|------|------|
| 0 | 0% | 꺼짐 |
| 64 | 25% | 어둡게 |
| 128 | 50% | 중간 |
| 255 | 100% | 최대 (= `digitalWrite(HIGH)`) |

> 💡 이름에 "analog" 가 있지만 **진짜 아날로그 전압이 아닙니다.** 빠른 디지털 점멸의 평균입니다.
> (진짜 아날로그 전압은 이 문서 5절의 DAC)

## 3. 예제 — 숨쉬는 LED (Fade) (코드: `examples/03-pwm-output/`)

밝기를 0→255→0 으로 천천히 오르내려 LED 가 숨 쉬듯 밝아지고 어두워집니다.

```cpp
#include <Arduino.h>

const int LED_PIN = 5;   // 외부 LED (내장 GPIO2 도 가능)

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // 0 → 255 점점 밝게
  for (int duty = 0; duty <= 255; duty++) {
    analogWrite(LED_PIN, duty);
    delay(5);
  }
  // 255 → 0 점점 어둡게
  for (int duty = 255; duty >= 0; duty--) {
    analogWrite(LED_PIN, duty);
    delay(5);
  }
}
```

배선은 [03](03-digital-output.md) 의 외부 LED 와 같습니다: `GPIO5 ──[220Ω]──▶|── GND`

> 💡 `delay(5)` 를 바꾸면 숨쉬는 속도가 변합니다. 256단계 × 5ms ≈ 1.3초에 한 번 밝아집니다.

## 4. PWM 이 쓰이는 곳

| 용도 | 어떻게 |
|------|--------|
| LED 밝기 | 듀티 = 밝기 |
| DC 모터 속도 | 듀티 = 속도 (모터 드라이버 필요) |
| 서보 모터 각도 | 특정 주파수(50Hz)의 펄스 폭 = 각도 (`ESP32Servo` 라이브러리) |
| 부저 음 높이 | 주파수 = 음 높이 (`tone()`) |
| RGB LED 색 | R·G·B 각각 PWM → 색 혼합 |

> 💡 `analogWrite` 는 내부적으로 ESP32 의 **LEDC(PWM) 하드웨어**를 씁니다. 주파수·해상도를 직접 조절하려면
> `ledcAttach`/`ledcWrite` 를 쓰지만, 입문에선 `analogWrite` 로 충분합니다.

## 5. (참고) 진짜 아날로그 출력 — DAC

**클래식 ESP32** 에는 진짜 아날로그 전압을 내보내는 **DAC (Digital-to-Analog Converter)** 가 **GPIO25, GPIO26 두 핀**에
있습니다. 값은 0~255 → 0~3.3V.

```cpp
dacWrite(25, 128);   // GPIO25 에 약 1.65V 의 "실제" 전압 출력
```

멀티미터로 재면 PWM 과 달리 **진짜 그 전압**이 나옵니다. 오디오 파형 출력 등에 쓰입니다.

> ⚠️ **DAC 는 클래식 ESP32 에만** 있습니다. ESP32-S3 / C3 등 신형 칩엔 없으니, 그 보드는 PWM 만 쓰세요.
> LED 밝기 조절엔 PWM 이 표준이고 DAC 는 거의 안 씁니다.

## 정리

| 구분 | 함수 | 값 범위 | 핀 | 비고 |
|------|------|---------|----|----|
| PWM (흉내) | `analogWrite()` | 0~255 | 대부분의 출력 핀 | 밝기·속도 제어 표준 |
| DAC (진짜) | `dacWrite()` | 0~255 | **GPIO25, 26만** | 클래식 ESP32 만 |
