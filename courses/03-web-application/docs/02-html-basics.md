# 02. HTML 기초 — 문서의 뼈대 만들기

## 한 줄 요약

> **HTML = 태그(`< >`)로 내용의 의미와 구조를 표현하는 언어.**
> 제목·문단·입력창·버튼·목록 같은 "재료"를 화면에 배치하는 **뼈대**입니다.

## 1. 태그(Tag)가 뭔가요?

HTML은 **태그**라는 꺽쇠 기호로 내용을 감싸서 "이건 제목이야", "이건 문단이야" 하고
**의미**를 부여합니다. 대부분 **여는 태그**와 **닫는 태그**가 짝을 이룹니다.

```html
<h1>안녕하세요</h1>
└┬─┘ └──┬──┘ └─┬─┘
여는    내용    닫는
태그          태그(/ 가 붙음)
```

- 여는 태그 `<h1>` ~ 닫는 태그 `</h1>` 사이에 들어간 내용이 **그 태그의 적용 대상**입니다.
- `<img>`, `<input>` 처럼 **내용이 없어 닫는 태그가 없는** 태그(빈 태그)도 있습니다.

> 💡 태그는 **중첩(nesting)** 될 수 있습니다. `<ul><li>항목</li></ul>` 처럼 태그 안에
> 다른 태그가 들어가요. 단, 순서가 엇갈리면 안 됩니다. (먼저 연 태그를 나중에 닫기)

## 2. HTML 문서의 기본 골격

모든 HTML 파일은 아래 뼈대로 시작합니다. 이 틀을 외워두면 어디서든 바로 시작할 수 있어요.

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8">
    <title>내 첫 페이지</title>
  </head>
  <body>
    <h1>여기에 보이는 내용을 씁니다</h1>
  </body>
</html>
```

| 부분 | 역할 |
|------|------|
| `<!DOCTYPE html>` | "이 문서는 HTML5 입니다" 라는 선언 (맨 첫 줄) |
| `<html lang="ko">` | 문서 전체를 감싸는 최상위 태그, 언어는 한국어 |
| `<head>` | **화면에 안 보이는** 설정 (인코딩, 제목, CSS 연결 등) |
| `<meta charset="UTF-8">` | 글자 인코딩 — **한글이 깨지지 않게** 해줍니다 |
| `<title>` | 브라우저 **탭에 표시되는** 제목 |
| `<body>` | **화면에 실제로 보이는** 모든 내용 |

> ⚠️ `<meta charset="UTF-8">` 을 빼먹으면 한글이 `???` 나 깨진 글자로 나올 수 있습니다.
> 한글을 쓴다면 꼭 넣어주세요!

## 3. 자주 쓰는 태그들

`<body>` 안에서 자주 만나는 태그들입니다. 이 정도면 웬만한 페이지를 만들 수 있어요.

| 태그 | 의미 | 예시 |
|------|------|------|
| `<h1>`~`<h6>` | 제목 (h1이 가장 큼) | `<h1>큰 제목</h1>` |
| `<p>` | 문단(paragraph) | `<p>본문 글입니다.</p>` |
| `<div>` | 의미 없는 **묶음 상자**(블록) | `<div>여러 요소 묶기</div>` |
| `<span>` | 의미 없는 **작은 묶음**(인라인) | `<span>글자 일부</span>` |
| `<ul>`/`<li>` | 목록(unordered list)과 항목 | `<ul><li>사과</li></ul>` |
| `<a>` | 링크(anchor) | `<a href="...">이동</a>` |
| `<img>` | 이미지 | `<img src="cat.png">` |
| `<input>` | 입력창 | `<input type="text">` |
| `<button>` | 버튼 | `<button>전송</button>` |
| `<form>` | 입력 요소를 묶는 양식 | `<form>...</form>` |

### div 와 span 의 차이 (블록 vs 인라인)

- **`<div>`(블록)**: 한 줄을 **통째로** 차지합니다. 위아래로 쌓입니다. → 영역/구역 나눌 때
- **`<span>`(인라인)**: 글자처럼 **필요한 만큼만** 차지합니다. → 글 일부만 강조할 때

## 4. 속성(Attribute) — 태그에 정보 더하기

태그에 **속성**을 붙여 추가 정보를 줄 수 있습니다. `이름="값"` 형태로 여는 태그 안에 씁니다.

```html
<a href="https://example.com">예제 사이트로 이동</a>
<img src="cat.png" alt="고양이 사진" width="200">
<input type="text" placeholder="여기에 입력하세요">
```

| 속성 | 쓰이는 곳 | 의미 |
|------|-----------|------|
| `href` | `<a>` | 이동할 주소 |
| `src` | `<img>` | 이미지 파일 경로 |
| `alt` | `<img>` | 이미지가 안 뜰 때 대신 보일 글 |
| `type` | `<input>` | 입력 종류 (`text`, `password`, `number` 등) |
| `placeholder` | `<input>` | 입력 전 흐리게 보이는 안내 문구 |

## 5. id 와 class — 요소에 이름표 붙이기

CSS로 꾸미거나 JavaScript로 다루려면, 요소를 **콕 집어 찾을** 수 있어야 합니다.
그때 쓰는 **이름표**가 `id` 와 `class` 입니다.

```html
<input id="name" class="field" placeholder="이름">
<button id="on" class="btn">켜기</button>
<ul id="history"></ul>
```

| 이름표 | 특징 | 비유 |
|--------|------|------|
| **`id`** | 페이지에서 **딱 하나**여야 함 (고유) | 주민등록번호 |
| **`class`** | **여러 요소가 공유** 가능 (그룹) | 같은 반 학생들 |

> 💡 규칙: **하나만 콕 집을 땐 `id`**, **여러 개를 같은 스타일로 묶을 땐 `class`**.
> [03. CSS](03-css-basics.md)와 [04. JavaScript](04-javascript-basics.md)에서 이 이름표로
> 요소를 찾아 씁니다. (CSS는 `#name`/`.field`, JS는 `getElementById("name")`)

## 6. 🧪 직접 해보기 — 실습에서 쓸 뼈대 만들기

이 강의의 핵심 실습은 **"이름을 넣고 → 켜기/끄기를 누르면 → 표시등이 바뀌고 아래에 기록이
쌓이는"** LED 제어판입니다. 그 HTML 뼈대를 미리 만들어 봅시다.

1. VS Code에서 `index.html` 파일을 새로 만듭니다.
2. 아래 내용을 그대로 입력합니다.

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8">
    <title>LED 제어판</title>
  </head>
  <body>
    <h1>💡 LED 제어판</h1>

    <div id="lamp">OFF</div>

    <input id="name" type="text" placeholder="이름">
    <button id="on">켜기</button>
    <button id="off">끄기</button>

    <ul id="history">
      <!-- 여기에 "누가 언제 켰/껐는지" 기록이 쌓일 예정 -->
    </ul>
  </body>
</html>
```

3. 파일을 저장하고, VS Code의 **Live Server** 확장으로 열거나 파일을 더블클릭해
   브라우저로 엽니다.

> 🧪 지금은 버튼을 눌러도 아무 일이 없습니다. 당연합니다 — **동작(JavaScript)** 을 아직
> 안 넣었으니까요! 우선 표시등·이름칸·버튼·빈 목록이 **화면에 보이는지**만 확인하면 성공입니다.
> 꾸미기는 [03. CSS](03-css-basics.md), 동작은 [04. JavaScript](04-javascript-basics.md)에서
> 이어집니다.
