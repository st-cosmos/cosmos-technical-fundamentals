# 예제 01 — LED 제어판 (정적 HTML/CSS/JS)

순수 **HTML/CSS/JS** 만으로 만든 페이지입니다. 이름을 넣고 **켜기 / 끄기** 를 누르면
표시등이 켜지고 꺼지며, "누가 언제 바꿨는지" 기록이 아래에 쌓입니다. **서버가 필요 없습니다.**

> 이 예제는 06-web-server-python 강좌의 **LED 제어 앱을 화면(정적)으로 먼저 만들어 보는** 단계입니다.
> 아직 서버가 없어 내 화면 안에서만 동작하고, 06 강좌에서 이 화면을 서버·ESP32와 연결합니다.

## 실행

`index.html` 파일을 더블클릭해서 브라우저로 열면 끝입니다.

> 💡 VS Code의 **Live Server** 확장으로 열면 코드 수정 시 자동 새로고침되어 편합니다.

## 파일

| 파일 | 역할 |
|------|------|
| `index.html` | 화면 구조 (이름 입력·켜기/끄기 버튼·표시등·기록 목록) |
| `style.css` | 모양(스타일) — 표시등 색 등 |
| `app.js` | 동작 (버튼 클릭 → 표시등 바꾸고 기록 추가) |
