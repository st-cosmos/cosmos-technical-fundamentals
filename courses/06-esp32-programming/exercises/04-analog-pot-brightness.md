# 실습 04. 가변저항으로 LED 밝기 조절 (아날로그 입력)

> 🎯 목표: **가변저항을 돌려** 그 값을 읽고(ADC 0~4095), `map()` 으로 변환해 **LED 밝기(PWM)** 로 연결한다.
> 입력 → 변환 → 출력의 한 바퀴.
>
> 📎 관련 문서: [docs/06-analog-input.md](../docs/06-analog-input.md) · 코드: `examples/04-analog-input/`

## 준비물

- ESP32 DevKit + USB 케이블
- 가변저항(포텐셔미터) 10kΩ
- LED + 220Ω 저항, 브레드보드, 점퍼선

## 1. 회로 연결

**가변저항** (3개 다리):

```
3.3V ──[가변저항 한쪽 끝]
GND  ──[가변저항 다른쪽 끝]
GPIO34 ──[가변저항 가운데 다리]   ← 돌리면 0~3.3V 로 변하는 값을 읽음
```

**LED** (PWM 출력, 실습 03 과 같음):

```
GPIO23 ──[220Ω]──▶|── GND
```

> 📌 가변저항 입력은 **GPIO34**(입력 전용, ADC1)를 씁니다. WiFi 와 함께 써도 안전한 핀입니다.

## 2. 코드 핵심

```cpp
int raw = analogRead(POT_PIN);          // 0 ~ 4095 (12비트)
int duty = map(raw, 0, 4095, 0, 255);   // 0~255 범위로 변환
analogWrite(LED_PIN, duty);             // PWM 으로 LED 밝기
```

`map()` 이 핵심입니다. 읽은 범위(0~4095)를 출력 범위(0~255)로 **비례 변환**합니다.

## 3. 업로드 & 확인

1. `examples/04-analog-input` 폴더 열기 → **Upload** → **Serial Monitor**
2. 가변저항을 천천히 돌리면:
   - **LED 밝기**가 부드럽게 변함
   - Serial 에 `raw=... volt=...V duty=...` 가 실시간으로 변함
3. 끝까지 돌렸을 때 `raw` 가 0 근처와 4095 근처가 되는지 확인

## 보너스: 진짜 DAC 전압 확인

예제 코드에는 `dacWrite(DAC_PIN, duty)` 한 줄이 들어 있습니다. 멀티미터가 있다면 **GPIO25** 와 GND 사이 전압을 재 보세요.
가변저항을 돌리면 **0~3.3V** 가 실제로 변합니다. (PWM 은 평균값 흉내지만 DAC 는 진짜 전압)

> ⚠️ DAC(GPIO25/26)는 **클래식 ESP32 에만** 있습니다. ESP32-S3/C3 보드라면 그 줄을 지우고 PWM 만 쓰세요.

## 직접 해보기 (도전 과제)

1. **임계값 스위치**: `raw` 가 2048 보다 크면 LED 완전히 켜고, 작으면 끄기 (아날로그 입력 + 디지털 출력).
2. **퍼센트 표시**: `map(raw, 0, 4095, 0, 100)` 으로 `밝기 73%` 처럼 출력.
3. **밝기 반전**: `duty = 255 - duty;` 를 추가해 돌리는 방향과 밝기를 반대로.
4. **값 안정화**: 10번 읽어 평균낸 값을 쓰면 흔들림이 줄어드는지 비교.

## 막히면?

| 증상 | 해결 |
|------|------|
| 값이 0 또는 4095 에 붙어서 안 변함 | 가운데 다리가 **GPIO34** 에, 양 끝이 3.3V/GND 에 연결됐는지 |
| LED 밝기가 안 변함 | LED 가 **GPIO23**·올바른 방향인지, `analogWrite` 호출 확인 |
| 값이 계속 흔들림 | 약간은 정상. 배선 헐거움 확인. 평균 내기(도전 4) |
| `dacWrite` 에서 에러 | DAC 는 GPIO25/26 만 가능. 신형 칩이면 그 줄 삭제 |
