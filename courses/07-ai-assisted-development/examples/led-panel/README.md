# 예제 — LED 제어판 (디자인 시안 → 코드 참고본)

이 폴더는 러닝 예제 **"LED 제어판"** 의 참고 결과물입니다. **디자인 시안(`preview.png`)을 AI 에이전트에게 보여 주고**
(`codex -i preview.png "..."`) 순수 HTML/CSS/JS 로 만들게 한 것을 사람이 검토·다듬은 버전입니다.
[실습 01](../../exercises/01-codex-led-panel.md) 7단계에서 같은 시안으로 직접 만들어 **비교**해 보세요.

> 🔗 이 "LED 제어판" 은 04(정적)·06(서버 연동) 강좌와 **같은 예제**입니다. 여기서는 **서버 없이** 브라우저 안에서만 동작하는
> 정적 버전(04 강좌 `examples/01-led-panel` 과 같은 기능, 다른 디자인)입니다.

## 파일

| 파일 | 역할 |
|------|------|
| `preview.png` | **디자인 시안** — 아래 코드가 이 시안을 옮긴 것 |
| `index.html` | 시안을 옮긴 화면 구조 |
| `style.css` | 색·간격 등 스타일 (디자인 토큰을 `:root` 변수로 모아 둠) |
| `script.js` | 켜기/끄기 동작 · 변경 이력 (순수 JS, `new Date()`) |

## 실행

브라우저로 `index.html` 을 그냥 열면 됩니다. (빌드/서버 불필요)
이름을 넣고 **켜기/끄기** 를 누르면 표시등과 **변경 이력**이 바뀝니다.

## 기능 요약 (디자인이 달라도 이 기능은 같게)

- **이름 입력** → 비우면 "익명"
- **켜기 / 끄기** 버튼
- **표시등**: 켜짐=노랑(빛남), 꺼짐=회색
- **변경 이력**: `[시각] 이름 님이 LED를 켰/껐습니다` 를 최신순으로 누적

## "다른 디자인"으로 만들어 보기

기능은 그대로 두고 **디자인만** 바꿔 보세요. 쉬운 출발점:

- `style.css` 의 `:root` **디자인 토큰**(색·radius)만 바꿔 분위기 바꾸기
- 표시등을 **전구 아이콘**이나 **네온 사인** 느낌으로 (에이전트에게 "다크 모드 + 네온" 으로 요청)
- 카드형 대신 **가로 배치**, 큼직한 토글 스위치 등
- 다른 시안 이미지를 `-i` 로 첨부해 "이 느낌으로" 요청 → 이 참고본과 비교
