# 실습 01. Codex 로 "LED 제어판" 만들기 🧭💡

> [02. Codex CLI 시작하기](../docs/02-getting-started-with-codex.md) 를 먼저 읽고, 00 강좌에서 설치·로그인을 마친 뒤 진행하세요.

## 🎯 목표

Codex 에게 **작은 웹 페이지를 요청**하고, 결과를 **검토 → 실행 → 수정 → 완성**하는 전체 흐름을 직접 경험합니다.
"요청 → 검토 → 피드백" 의 반복이 손에 익습니다.

만들 것: **브라우저에서 도는 "LED 제어판" 웹 페이지** (순수 HTML/CSS/JS, 서버 없음)

> 🔗 이 "LED 제어판" 은 03·05 강좌와 **같은 러닝 예제**입니다. 03 에서 손으로 만든 것을, 여기서는 **말로 시켜서** 만들어
> 두 방식을 비교합니다. 참고 완성본: `examples/led-panel/` (시안 `preview.png` 포함)

## 🧰 준비

- 설치·로그인이 끝난 **Codex CLI** (`codex --version`, `codex login status`)
- 실습용 **빈 폴더** 하나 (`~/workspace/led-panel-codex`)
- 결과 확인용 **웹 브라우저**

> 💡 명령·화면 문구는 버전에 따라 다를 수 있습니다. 똑같지 않아도 **비슷한 기능**을 찾으세요 (`/` 목록, `codex --help`).

## 📝 단계별 따라하기

### 1단계 — 폴더 만들고 git 안전망

```bash
cd ~/workspace             # 동아리 규칙: 프로젝트는 전부 이 안에
mkdir led-panel-codex
cd led-panel-codex
git init
codex
```

(빈 저장소라 첫 커밋은 파일이 생긴 뒤에 합니다)

### 2단계 — 첫 요청 (구체적으로)

```
순수 HTML/CSS/JS 로 "LED 제어판" 웹 페이지를 만들어줘. 파일은 index.html, style.css, script.js 세 개.
- 제목 "💡 LED 제어판"
- 동그란 표시등 하나 (기본은 꺼짐=회색)
- 이름 입력칸 + "켜기" / "끄기" 버튼
- "변경 이력" 목록 (빈 ul)
- 포인트 색은 보라색(#6b4e9e). 서버 없이 브라우저에서만 동작. 아직 버튼 동작은 넣지 말고 화면만.
```

### 3단계 — 변경 검토하기

에이전트가 파일을 만들면, **바로 다음 요청으로 넘어가지 말고** 먼저 살펴봅니다.

```
› /diff
```

- 세 파일이 만들어졌나? 요청한 요소(표시등·입력칸·버튼·이력)가 **코드에 들어 있나**?
- 이해 안 되는 부분은 **"style.css 의 표시등 부분을 한 줄씩 설명해줘"**

> 💡 검토는 "맞는지 보는 것". **그럴듯해 보인다 ≠ 맞다.** 다음 단계에서 꼭 **실행**해 봅니다.

### 4단계 — 실행해서 확인

파일 탐색기에서 `index.html` 을 더블클릭하거나, 에이전트에게 맡깁니다.

```
› index.html 을 확인할 수 있게 이 폴더에서 간단한 로컬 서버를 띄워줘 (python -m http.server 같은 걸로)
```

→ **명령 실행 승인 요청**이 뜹니다. 명령을 **읽고** 승인. 브라우저에서 `http://localhost:8000` 확인.

화면이 나오면 첫 커밋:

```bash
git add . && git commit -m "LED 제어판 화면"     # 다른 터미널에서, 또는 에이전트에게 "커밋해줘"
```

### 5단계 — 동작 붙이기 (피드백)

```
› "켜기"를 누르면 표시등을 노란색(#f5b301)으로, "끄기"를 누르면 회색(#cfc9dc)으로 바꿔줘.
  그리고 누를 때마다 "[시각] 이름 님이 LED를 켰습니다"(또는 껐습니다)를 변경 이력 목록 맨 위에 추가해줘.
  이름이 비어 있으면 "익명". 시각은 new Date().toLocaleTimeString(). script.js 만 고쳐줘.
```

→ `/diff` 로 **script.js 만** 바뀌었는지 확인 → 브라우저 새로고침 → 눌러 보기 → 커밋.

### 6단계 — 한 번 더 다듬기

작은 개선을 하나 더 요청해 반복을 익혀 보세요. (한 번에 하나!)

```
› 켜졌을 때 표시등에서 노란빛이 은은하게 번지도록 box-shadow 효과를 넣어줘.
› 이력 항목 앞에 켜짐/꺼짐 상태 색 점을 붙여줘.
```

### 7단계 — 시안대로 만들어 보기 (이미지 첨부)

`examples/led-panel/preview.png` 를 이 폴더로 복사한 뒤:

```bash
codex -i preview.png "이 시안과 같은 느낌으로 index.html 과 style.css 를 다시 꾸며줘. 기능(script.js)은 그대로."
```

→ 참고 완성본 `examples/led-panel/` 과 **비교**해 보세요. 같은 시안이라도 결과는 다릅니다.

## ✅ 확인

- [ ] `index.html` / `style.css` / `script.js` 가 폴더에 생겼다
- [ ] 브라우저에서 표시등·입력칸·버튼·이력이 **보인다**
- [ ] **켜기/끄기** 를 누르면 표시등 색이 바뀐다
- [ ] 누를 때마다 변경 이력이 **최신순으로** 쌓인다
- [ ] 적어도 한 번 **`/diff` 검토 → 실행 → 피드백 → 커밋** 을 직접 돌려 봤다
- [ ] 명령 실행 승인 요청을 **읽고** 승인해 봤다

## 🆘 막히면

| 증상 | 해결 |
|------|------|
| 결과가 엉뚱함 | 요청이 모호했을 확률 ↑ → **요소·동작·파일**을 더 구체적으로 다시 요청 |
| 코드가 이해 안 됨 | **"이 코드를 한 줄씩 설명해줘"** |
| 버튼을 눌러도 반응 없음 | "F12 Console 에 이런 에러가 나" + 에러 붙이기, 또는 "script.js 가 index.html 에 연결됐는지 확인해줘" |
| 파일이 엉뚱한 곳에 생김 | `codex` 를 실행한 폴더 확인 (`pwd`) |
| 마음에 안 드는 변경 | `git restore .` 로 되돌리고 다시 요청 |
| 화면·명령이 자료와 다름 | **버전 차이**(정상). `/` 목록·`codex --help` |

> 💡 막혔을 때도 **에러 메시지를 그대로 붙여** 물어보면 원인을 잘 찾아 줍니다.
